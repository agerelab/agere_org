# Agere DS v4

Storybook is the **engineering workshop**: isolated states, controls, the a11y panel and Chromatic visual tests.
Guidelines, do's & don'ts and foundations live in the **documentation portal** (`npm run dev`).

- Toggle light / dark with the theme switcher in the toolbar.
- The **Accessibility** panel runs axe-core on every story; violations fail CI.
- Chromatic snapshots every story in both modes (`parameters.chromatic.modes`).
