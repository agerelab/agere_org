# Changelog

All notable changes to `@agere/design-system`. Format: [Keep a Changelog](https://keepachangelog.com) · [SemVer](https://semver.org).
Entries after 4.0.0 are generated by Changesets.

## 7.0.0 — 2026-10-01

Major. **Visual contract and default sizes change; the component API does not.** No prop, variant or semantic token was renamed or
removed. Run `npm run codemod:v7` in each app (it never touches `secondary`) and plan a visual review per product.

### Changed — Geist visual language
- **Colour.** Semantic tokens now resolve to Geist scales per theme (`color.geist.{light,dark}.*`: background-100/200, gray 100–1000 and
  blue, red, amber, green, teal, purple, pink 100–1000 + `on-solid`), contrast-solved in oklch. Status roles: info → blue, success → green,
  attention → amber, error → red, special → purple; `bg` 100 · `border` 400 · `solid` 700 · `fg` / `on-surface` / `icon` 900. The chart and
  viz palettes are unchanged (validated for colour-vision deficiency in 6.3). Mobile outputs (iOS, Android, Compose) regenerated.
- **Where agere deviates from Geist** (accessibility; `data-contrast="geist"` restores upstream values): `border.control` gray-700 (Geist uses
  gray-alpha-400, 1.2:1); light gray-700 `#8f8f8f → #8a8a8a` (2.89:1 on gray-100); light gray-800 `#7d7d7d → #737373`; dark gray-700 / 800 / 900
  `#6e6e6e / #7d7d7d / #a1a1a1 → #7a7a7a / #9a9a9a / #b4b4b4` (Geist's pass WCAG but fail APCA, Lc 33–51).
- **Type.** Geist Sans and Geist Mono (Variable, self-hosted, SIL OFL) replace Inter. The 16 `type-*` names stay; tracking tight −0.025em,
  display −0.05em. `@fontsource-variable/inter` is no longer a dependency.
- **Size.** Button / Input / InputGroup / InputOTP / Combobox / Toggle / Tabs list / NavigationMenu / Menubar: md 36 → **40 px**, lg 40 → **48 px**
  (`component.button|input.height.*` updated). xs 24 and sm 32 unchanged; dense workspace modules (filter bar, nav rows) keep their density.
- **Radius.** `--radius` 10 → 8 px with Geist steps: sm 4 · md/control 6 · lg 8 · xl 12 · 2xl 16.
- **Elevation.** `shadow.elevation-1…5` are Geist's layered materials (ambient + direct). `shadow-button-*` resolve to `none`.
- **Focus.** Solid 2 px ring separated by a 2 px page-colour gap (was a 3 px ring at 50% alpha, ≈2:1 with blue). Fields keep the ring-coloured
  border plus a 20% halo. `--ring-alpha` defaults to 1. Ring colour is blue-700.
- **Hover increases contrast.** Button `default` hovers to `primary-hover` (black in light, white in dark), `destructive` to `destructive-hover`,
  `secondary` to `bg-emphasis`, Toast action to `primary-hover` — no more faded `/90` and `/80`.
- `data-contrast="geist"` replaces `data-contrast="shadcn"`; `"shadcn"` keeps working as a **deprecated alias** (announced here).

### Added
- Tokens `{info,success,attention,error,special}.solid-hover`; Tailwind `bg-*-solid-hover`, `bg-destructive-hover`; CSS `--destructive-hover`.
- `apcaContrast()` in `@/lib/theme` (APCA-W3 0.0.98G, checked against reference values).
- **AGENTS.md** (for coding agents) and **GUIDELINES.md** (PR checklist), generated from `src/docs/registry/interface-rules.ts`: 67 rules,
  42 enforced automatically. Adapted from Vercel's Web Interface Guidelines. Docs → Guidelines → **Interface rules**.

  div/span, blocked paste, search placeholder `…`, image dimensions, lowercase brand, unit glue; G12 placeholder-in-authoring-field warns).
- `npm run check:jsx-comments` — fails when a `//` line inside JSX children would render as text (TypeScript accepts it).
- `npm run verify:browser` — Chromium: axe with **contrast on** for 10 routes × light/dark, focus ring, hover, dialog focus and scroll
  containment, skip link, Geist loaded, 40 px default, 390 px overflow, 16 px inputs, touch-action. 41 checks.
- `npm run codemod:v7`. Global rules in `globals.css`: `touch-action: manipulation` on controls, tap-highlight colour, `scroll-margin-top` on
  headings and anchors, `overscroll-behavior: contain` in dialogs, sheets and drawers.
- CI runs all of the above; `ci` script and `.github/workflows/ci.yml` updated.
- **Tests:** 441 (from 341). Contrast suite 205 (from 108): APCA body Lc ≥ 60 and UI Lc ≥ 45 in both themes, status text on `bg.subtle`,
  task-status chips, sidebar pairs, focus ring and control borders on subtle fills, hover-increases-contrast.

### Deprecated (lifecycle step 2 — Warn)

  Announced in 6.0.0 on 2026-09-25, so per VERSIONING.md (≥ 90 days) they are removed in the **first major on or after 2026-12-24** —
  not in 7.0 as the 6.x comments said. Same for `shadow-button-*` and `data-contrast="shadcn"`.

- **Skip link dropped users on the home page in hash-routed apps.** AppShell's `href="#main-content"` replaced `#/route`. It now moves focus
  programmatically and keeps the URL (since 6.x; found by the new Chromium check).
- **Workspace ViewSwitcherBar tab panel had no focus indicator** (Radix gives it `tabIndex=0`). Adds `focus-ring`.
- **Sidebar collapse animated `width` / `left` / `right`** (reflowed the whole page every frame). Collapse now snaps; a transform-based
  slide is planned for 7.1. Menu buttons transition colour only.
- `transition-all` removed from Accordion, Carousel dots, InputOTP, NavigationMenu links, Sidebar rail and Switch.
- Kanban card covers, TaskFields avatars and the brand page logos had no `width` / `height` (layout shift).
- Two-letter initials were clipped in small avatar stacks (Kanban cards); xs/sm `MemberAvatar` shows one letter.
- Priority "high" flag was 1.65:1 under the first Geist mapping; uses amber 900.
- Full-screen block routes had no `<main>` (and Kanban/Calendar/Timeline/Map no `<h1>`); the Dashboard skipped from h1 to h3.
- Docs that were stale before 7.0: Button spec "sm 28" (32 since 6.0), Typography card "Cal Sans", radius table "control 10px", an Input
  demo labelled "Large" that rendered the default size.
- Visible brand copy is lowercase "agere" (70 strings: "agere DS", "agere workspace", sample products); the legal name
  PT Agere Teknologi Indonesia keeps its casing.
- Search placeholders end with "…"; numbers and units are glued with a no-break space in docs tables.

### Known backlog
- **G12 — 39 authoring fields still use a placeholder** (6.4 Forms guideline says label + helper text instead). Listed by
  `npm run lint:guidelines -- --warnings`; each needs a design decision, so it warns rather than fails.

## 6.4.0 — 2026-09-28

Minor, **non-breaking**. Everything new has a safe default; no prop, token or variant was renamed or removed.

### Added
- **Tokens:** `info · success · attention · error · special` › `on-surface` — status-coloured *text* on neutral surfaces
  (`bg.default`, `bg.muted`, `bg.surface`). Light: the 800 step; dark: the 300 step (error: red 400). The `-fg` tokens stay for text *on*
  the status `-bg`. Contrast suite: every pair ≥ 4.5:1 (measured 6.21–11.00:1) and saturation ≥ 40 % so dark text never fades to near-white.
  Tailwind: `text-error-on-surface` etc. Mobile outputs (Android, Compose, iOS) regenerated.
- **Components:** `PageHeader` (Leading · Content · Back · Title with badges · Description · Meta · Actions). `PageHeaderActions` encodes the
  action hierarchy — one labelled `primary` (default), at most two `secondary` (outline, type-enforced), a ⋯ `menu`; below `md` the secondary
  actions become the first ⋯ items. `SaveBar` (sticky explicit-save footer with a polite status). `SaveStatus` (inline Saved · Saving… ·
  Couldn’t save · Offline for autosaving surfaces). `RuleBuilder` (When · Where · If · Then rows with a sentence preview in a status region).
- **Toaster:** `position` (`bottom-center` default — unchanged — `bottom-left`, `bottom-right`) and `offset` (px), so toasts never cover a SaveBar
  or right-aligned dialog footers.
- **Helpers:** `getDropZone`, `canDrop`, `moveTreeItem`, `siblingsOf` (`@/lib/tree`) — the drop semantics of the Nested list pattern as pure,
  tested functions; `devWarn` (dev-only, once per message).
- **Docs:** Foundations → Semantic status now shows seven roles (adds `on-surface`). Guidelines → **Actions & CTA** (variant hierarchy, size per context, page-header rules, one action one place, general verbs such as
  Import/Export). Forms guideline: placeholders only in search fields; authoring fields get a visible label and helper text.
  Patterns → **Nested list** (tasks → subtasks, drag zones, keyboard alternatives) and **Block editor** (always editable, autosaved, no placeholder).
- **Tests:** 341 (from 327 in the unreleased draft; 273 in 6.3.0).

### Changed
- `destructive-outline` text uses `error-on-surface` (hover: `error-fg` on `error-bg`). Before, it used `error-fg`, which is near-white in dark mode,
  so destructive entry points didn't read as destructive. **Visual change** in dark mode only.
- Status text on neutral surfaces moved from `-fg` to `-on-surface` in Chat (error, thread link), Finance (income), Time tracker (errors, over estimate),
  Kanban card (overdue, subtasks done), Task fields (overdue date), File uploader, Auth password rules, Workflow builder and the Brand docs.
  **Visual change** in dark mode only.

### Fixed
- **`DropdownMenuItem asChild` threw** — Radix Slot received the injected icon and shortcut as extra children. With `asChild`, put the icon inside
  the child element.
- Toast docs described an inverted surface (`bg.inverted`, `radius.xl`, `elevation-4`); the component has always used `bg-popover`, border,
  radius `lg`, `shadow-lg`. The spec table now matches the code.
- README listed "Screen-reader passes" twice under *Not yet done*; `package-lock.json` still said 6.1.0.

### Provenance
- `page-header.tsx`, `save-bar.tsx`, `rule-builder.tsx`, the `on-surface` tokens, the Actions & CTA page, the Nested list and Block editor patterns
  and `v64-components.test.tsx` were drafted by a parallel session in this workspace (28 Sep, 01:48–01:56 UTC) from the agere/org prototype's
  CTA audit. They were reviewed line by line against the prototype before adoption. Added in review: the duplicate-action dev warning in
  `PageHeaderActions` (the one-action-one-place rule was documented but not checked), `Toaster` `position`/`offset` (the SaveBar docs told
  teams to stack toasts bottom-left, which the Toaster could not do), `SaveStatus` (the Block editor pattern specified a status with no
  component), the tree helpers, the Toast spec fix and `v64-additions.test.tsx` (14 tests).

## 6.0.0 — 2026-09-25

The **shadcn/ui visual language**, and **shadcnstudio-style Dashboard & Application blocks**. Components and blocks copied
from ui.shadcn.com / shadcnstudio.com paste in with the same class names and component APIs. Run `npm run codemod:v6`.

### ⚠ Breaking
- **Visual language → shadcn/ui (neutral base).** Palette = Tailwind v4 neutral, exact hex of shadcn's oklch values
  (`--background #fff`, `--primary #171717`, dark `--background #0a0a0a`, dark `--card #171717`). One family (Inter; **Cal Sans removed**),
  headings `font-semibold tracking-tight`. Tailwind v4 shadow scale (`shadow-xs` on controls, `shadow-sm` on cards); the layered
  cal.com button shadows are gone (`shadow-button-*` resolve to `shadow-xs` until v7). `opacity.disabled` 0.4 → 0.5.
- **Radius is derived from one variable**, `--radius: 0.625rem`: `sm` 6 · `md`/`control` 8 · `lg` 10 · `xl` 14 · `2xl` 18 · `3xl` 22 · `4xl` 26.
  Override `--radius` on any subtree to re-round it.
- **Button variants use shadcn names.** `default` (was `primary`) · `secondary` = **filled gray** (was the bordered button) ·
  `outline` (the v5 `secondary`) · `ghost` (was `minimal`) · `destructive` = **solid** (was `destructive-solid`) ·
  `destructive-outline` (the v5 `destructive`) · `link`. `primary`, `minimal`, `destructive-solid`, `accent` remain as deprecated
  aliases (removed in v7) and report their v6 name in `data-variant`. Sizes: `sm` 28 → **32px**; padding follows shadcn (`px-4`, icon-aware).
- **Input / Select / Textarea default size is `md` = 36px** (shadcn `h-9`, `text-base md:text-sm`). `lg` = 40px stays available.
- **Tabs default variant is `default`** (muted track, active tab lifts) — was `pills`. `segmented` is an alias of `default`.
- **Card anatomy:** `py-6 gap-6`, header is a grid with the new `<CardAction>` slot, `CardFooter` has no muted strip. Dialog/Sheet/AlertDialog footers
  lose the muted strip too; dialogs are `rounded-lg p-6 gap-4`. Tooltip is `bg-primary`. Toast uses the popover surface.
- **Badge default variant is `default`** (solid primary), per shadcn. Pass `variant="gray"` for the v5 look.

### Added
- **Sidebar system (shadcn):** `SidebarProvider`, `Sidebar` (`collapsible` offcanvas / icon / none · `variant` sidebar / floating / inset),
  `SidebarTrigger`, `SidebarRail`, `SidebarInset`, groups, menus, sub-menus, badges, actions, skeletons, `useSidebar`, ⌘B / Ctrl+B,
  cookie persistence, mobile sheet below 768px. Works **without** a provider, so v5 `AppShell` / `SidebarSection` / `SidebarItem` keep working (deprecated).
- **Components:** `Table` primitives, `Chart` (`ChartContainer`, `ChartTooltip(Content)`, `ChartLegend(Content)` on Recharts 3),
  `Accordion`, `Toggle`, `ToggleGroup`, `ScrollArea`, `HoverCard`, `CardAction`, `useIsMobile`.
  `ChartContainer` normalises `var(--chart-1)` → `hsl(var(--chart-1))`, so shadcn v4 chart configs work on this Tailwind 3 token format.
- **Tokens:** `chart.1…5` (light + dark), `sidebar.*`, `bg.surface` (card/popover), `radius.base`, `radius.4xl`, `shadow.elevation-5`,
  primitives `neutral.450` / `neutral.550` (a11y steps). CSS exposes every shadcn theme variable (`--card`, `--chart-*`, `--sidebar-primary`, `--radius` …).
- **Blocks** (`src/blocks`, docs portal → Library → Blocks): dashboard shell (sidebar + header + ⌘K), statistics cards, 4 charts
  (interactive area, stacked bar, donut, radial goal), 4 widgets (recent sales, activity, team, usage), orders datatable,
  account settings, multi-step form, invite dialog, empty state — plus a full-screen dashboard route (`#/blocks/dashboard/full`).
- **Contrast modes:** `data-contrast="shadcn"` = pixel-exact shadcn borders and muted text (documented as **not** AA).
- **Codemod:** `npm run codemod:v6 -- src` rewrites Button variants inside `<Button>`, `<IconButton>`, `<ButtonGroup>` and `buttonVariants()` (`--dry`, `--tags=`).
- **Tests:** 181 (from 159) — new component/block behaviour + axe, v6 Button/Input contract, sidebar tokens contrast.

### Accessibility (where v6 intentionally differs from shadcn)
- `--input` = `#8c8c8c` (shadcn `#e5e5e5`, 1.26:1 — fails WCAG 1.4.11). `--muted-foreground` = `#6b6b6b` (shadcn `#737373`, 4.35:1 on `--muted`).
  `--ring` = `#737373` (shadcn `#a1a1a1`, 2.6:1). The 3px halo keeps shadcn's 50 % alpha; `data-contrast="more"` makes it opaque.
- Focus rings are box-shadow + a transparent outline, so Windows forced-colors still paints a focus indicator.

### Fixed
- `FormField hideLabel` no longer leaves an empty grid row (controls now align with neighbours).
- Blocks: empty `<th>` on action columns, focus-to-first-invalid ran before render, auto-slug stopped after one character,
